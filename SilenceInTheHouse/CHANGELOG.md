# Changelog


Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
версионирование соответствует [Semantic Versioning](https://semver.org/lang/ru/).

## [0.8.0] — 2026-11-08

### Добавлено
- Новые источники света (Directional и Point Lights) для создания атмосферного ночного освещения в интерьере дома.
- Дополнительные элементы мебели и декора в сцене `MainLevel` для улучшения визуального наполнения и плотности окружения.
- Финальная интеграция и настройка тяжелых звуков шагов (топота) монстра, полностью синхронизированных с его анимацией и текущей скоростью передвижения.

### Изменено
- Небольшие корректировки параметров освещения в сцене `MainLevel` для усиления хоррор-атмосферы и контраста теней.

### Примечания
- При добавлении новой мебели в сцену рекомендуется проверять, не перекрывают ли новые объекты пути навигации (NavMesh), и при необходимости выполнять перепеку (Bake).

## [0.7.0] — 2026-11-07

### Добавлено
- Новая сцена загрузки (`LoadingScene`) с асинхронной загрузкой уровня для предотвращения фризов.
- UI-анимация загрузки: вращающийся круг и прыгающие точки с плавной волной.
- Система гарантированного затемнения (`Black Screen Fade`) в начале игровой сцены для скрытия инициализации 3D-мира до начала кат-сцены.

### Изменено
- Полностью переработан поток запуска игры: `MainMenu` → `LoadingScene` → `MainLevel`.
- Обновлен `MainMenu.cs`: кнопка «Играть» теперь перенаправляет на сцену загрузки.
- Переработана логика `CutscenePlayer.cs` и `CutsceneStarter.cs`: убрана искусственная задержка перед стартом, черный экран теперь надежно скрывает уровень, а плавное появление геймплея происходит только после полного завершения видео.
- Настроены приоритеты отрисовки (`Sort Order`): `CutsceneCanvas` (20) теперь гарантированно отображается поверх `GameUICanvas` (10).
- Оптимизирован видеофайл кат-сцены: перекодирован в формат MP4 с кодеком H.264 (Baseline profile) и включенной опцией "Web Optimized" для нативной поддержки Unity.

### Исправлено
- Критический баг: игрок больше не видит 3D-уровень и модель персонажа на долю секунды перед началом вступительной кат-сцены.
- Исправлено прохождение монстра сквозь стены: принудительно включен флаг `Navigation Static` для объектов окружения и выполнена корректная перепека (Bake) NavMesh с увеличенным `Agent Radius` (0.5).
- Устранена ошибка видеоплеера `WindowsVideoMedia error 0xc00d36c4` и предупреждение о смещении временных меток (Unexpected timestamp values).

### Примечания
- Для корректной работы видеоплеера файл кат-сцены должен быть перекодирован через HandBrake (Format: MP4, Video Codec: H.264, галочка Web Optimized).
- При добавлении новых статичных объектов в сцену необходимо проверять наличие галочки `Navigation Static` и выполнять пере запеку NavMesh.

## [0.6.1] — 2026-11-03

### Добавлено

- Добавлены 3D-звуки шагов монстра.
- Реализовано чередование двух звуковых файлов шагов.
- Добавлено автоматическое воспроизведение шагов во время движения монстра.
- Реализовано изменение частоты шагов в зависимости от скорости передвижения.
- Добавлена настройка громкости, высоты тона и дистанции слышимости шагов.

### Изменено

- Создан отдельный скрипт `MonsterFootsteps.cs` для управления звуками шагов.
- Настроено пространственное 3D-воспроизведение звуков монстра.
- Сохранён тяжёлый тембр шагов при переходе монстра на бег.

### Проверено

- Чередование звуков шагов во время движения.
- Изменение частоты шагов при переходе от ходьбы к бегу.
- Прекращение воспроизведения новых шагов при остановке монстра.
- Пространственное звучание шагов на расстоянии.

### Примечания

- Для работы необходимо назначить два аудиофайла шагов в Inspector.
- Скрипт `MonsterFootsteps.cs` должен находиться на объекте монстра с компонентом `NavMeshAgent` и `AudioSource`.
- Параметры громкости, тембра и частоты шагов можно настроить в Inspector.

## [0.4.0] — 2026-10-09

### Добавлено
- Полноценная аудиосистема на базе `AudioManager` с использованием `AudioMixer`.
- Раздельное управление громкостью музыки и звуковых эффектов (SFX) через группы микшера.
- Гитарная фоновая мелодия в главном меню (зацикленная, с плавным затуханием).
- Плавное появление музыки во время кат-сцены завершения уровня (fade-in за 3 секунды).
- Видео кат-сцены завершения уровня (`catscenes_LevelOver.mp4`) с автоматическим возвратом в главное меню.
- Разблокировка курсора мыши при возврате в главное меню.

### Изменено
- Скрипт `Bed.cs` переписан: управление игроком блокируется при победе, видео запускается через `LevelCompleteVideo.PlayVideo()`.
- `CutscenePlayer.cs` теперь останавливает музыку меню перед началом кат-сцены.
- Выпадающие списки настроек переведены на полностью спрайтовый интерфейс (без Unity Text).

### Исправлено
- Курсор больше не остаётся заблокированным после возврата в главное меню.
- Панель подтверждения выхода корректно блокирует наведение на кнопки под ней (Raycast Target).
- Устранена ошибка «неоднозначность SettingsMenu» (удалён дубликат класса).
- Музыка теперь корректно появляется во время видео завершения уровня, а не после перехода в меню.

### Известные проблемы
- Предупреждение Unity о H.264 baseline profile для некоторых видео (не критично, видео воспроизводится нормально).
- На слабых интегрированных видеокартах возможны микро-фризы при первом запуске видео.

## [0.3.0] — 2026-10-05

### Добавлено
- Главное меню с кнопками «Играть», «Настройки», «Выход» на спрайтах из Aseprite.
- Анимация кнопок при наведении (смена спрайта normal → hover).
- Панель настроек с двумя разделами:
  - **Графика**: выбор разрешения (5 вариантов) и режима экрана (3 варианта).
  - **Звук**: ползунок громкости с визуальным заполнением шкалы.
- Подтверждение выхода с панелью «Да / Нет».
- Плавное затемнение экрана (Fade Overlay) при переходах между сценами.
- Сохранение настроек в `PlayerPrefs` (разрешение, режим экрана, громкость).

### Изменено
- Логика загрузки уровня: кат-сцена пробуждения запускается только после полного затемнения экрана.
- Структура UI реорганизована: отдельные Canvas для меню, игры и кат-сцен.

### Исправлено
- Текст «Уровень завершен» корректно отображается в центре экрана.
- Монстр больше не атакует во время анимации победы игрока (добавлен флаг `playerHasWon`).
- Устранён баг, когда кат-сцена пробуждения запускалась автоматически при старте игры.
