# Changelog


Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
версионирование соответствует [Semantic Versioning](https://semver.org/lang/ru/).

## [0.6.0] — 2026-10-26

### Добавлено
- Механика пряток в шкафу с использованием клавиши взаимодействия `E`.
- Возможность осматриваться внутри шкафа с ограничением поворота камеры.
- Точка проверки шкафа для монстра при обнаружении спрятавшегося игрока.
- Ожидание монстра возле шкафа перед возобновлением патрулирования.

### Изменено
- Доработан `MonsterAI.cs`: расширена логика взаимодействия монстра с игроком во время пряток.
- Уточнена обработка состояний патрулирования, преследования и атаки.
- Доработано поведение монстра после выхода игрока из шкафа.
- Восстановлена корректная ориентация модели монстра во время движения.

### Исправлено
- Исправлена логика взаимодействия монстра с игроком во время входа в шкаф.
- Доработано восстановление управления игроком после выхода из шкафа.
- Исправлена блокировка и скрытие курсора мыши после выхода из шкафа.

### Проверено
- Механика пряток в шкафу и управление камерой внутри него.
- Поведение монстра при обнаружении игрока и во время преследования.
- Восстановление управления и блокировки курсора после выхода из шкафа.

### Примечания
- Для корректной работы механики необходимо назначить соответствующие точки шкафа и ссылки на объекты в Inspector.
- Поведение монстра и механику пряток следует дополнительно проверить в различных игровых ситуациях.

## [0.5.0] — 2026-10-23

### Добавлено
- Отображение текущего уровня громкости в процентах с обновлением в реальном времени.
- Возможность сброса настроек до значений по умолчанию.
- Обновление отображения выбранного разрешения и режима экрана в спрайтовых выпадающих списках.
- Дополнительные диагностические сообщения для действий главного меню и настроек.
- Документация по структуре проекта, запуску, тестированию и совместимости в `README.md`.

### Изменено
- Доработан `MainMenu.cs`: централизована обработка переходов между главным меню и настройками.
- Доработан `SettingsMenu.cs`: объединена обработка разрешения экрана, режима отображения, громкости, сохранения и сброса настроек.
- Доработан `SmartDropdown.cs`: добавлено обновление отображаемого выбранного варианта по его параметрам.
- Уточнены ссылки между объектами `MainMenuManager`, `SettingsMenuManager`, `MainMenuButtons` и `SettingsCanvas`.
- Обновлена документация изменений проекта в `CHANGELOG.md`.

### Исправлено
- Исправлено открытие панели настроек из главного меню.
- Исправлено возвращение к кнопкам главного меню после закрытия настроек.
- Исправлена обработка кнопок «Сохранить», «Сбросить» и «Назад».
- Исправлено отображение процентов громкости при перемещении ползунка.
- Доработано отображение выбранных параметров в выпадающих списках после загрузки настроек и сброса значений.

### Проверено
- Переход между главным меню и панелью настроек.
- Работа кнопок сохранения, сброса и возврата.
- Обновление процентов громкости в реальном времени.
- Отображение выбранных параметров разрешения и режима экрана.

### Примечания
- Настройки сохраняются с использованием `PlayerPrefs`.
- Фактическая совместимость с дополнительными конфигурациями оборудования требует отдельного тестирования.

## [0.4.0] — 2026-10-09

### Добавлено
- Полноценная аудиосистема на базе `AudioManager` с использованием `AudioMixer`.
- Раздельное управление громкостью музыки и звуковых эффектов (SFX) через группы микшера.
- Гитарная фоновая мелодия в главном меню (зацикленная, с плавным затуханием).
- Плавное появление музыки во время кат-сцены завершения уровня (fade-in за 3 секунды).
- Видео кат-сцены завершения уровня (`catscenes_LevelOver.mp4`) с автоматическим возвратом в главное меню.
- Разблокировка курсора мыши при возврате в главное меню.

### Изменено
- Скрипт `Bed.cs` переписан: управление игроком блокируется при победе, видео запускается через `LevelCompleteVideo.PlayVideo()`.
- `CutscenePlayer.cs` теперь останавливает музыку меню перед началом кат-сцены.
- Выпадающие списки настроек переведены на полностью спрайтовый интерфейс (без Unity Text).

### Исправлено
- Курсор больше не остаётся заблокированным после возврата в главное меню.
- Панель подтверждения выхода корректно блокирует наведение на кнопки под ней (Raycast Target).
- Устранена ошибка «неоднозначность SettingsMenu» (удалён дубликат класса).
- Музыка теперь корректно появляется во время видео завершения уровня, а не после перехода в меню.

### Известные проблемы
- Предупреждение Unity о H.264 baseline profile для некоторых видео (не критично, видео воспроизводится нормально).
- На слабых интегрированных видеокартах возможны микро-фризы при первом запуске видео.

## [0.3.0] — 2026-10-05

### Добавлено
- Главное меню с кнопками «Играть», «Настройки», «Выход» на спрайтах из Aseprite.
- Анимация кнопок при наведении (смена спрайта normal → hover).
- Панель настроек с двумя разделами:
  - **Графика**: выбор разрешения (5 вариантов) и режима экрана (3 варианта).
  - **Звук**: ползунок громкости с визуальным заполнением шкалы.
- Подтверждение выхода с панелью «Да / Нет».
- Плавное затемнение экрана (Fade Overlay) при переходах между сценами.
- Сохранение настроек в `PlayerPrefs` (разрешение, режим экрана, громкость).

### Изменено
- Логика загрузки уровня: кат-сцена пробуждения запускается только после полного затемнения экрана.
- Структура UI реорганизована: отдельные Canvas для меню, игры и кат-сцен.

### Исправлено
- Текст «Уровень завершен» корректно отображается в центре экрана.
- Монстр больше не атакует во время анимации победы игрока (добавлен флаг `playerHasWon`).
- Устранён баг, когда кат-сцена пробуждения запускалась автоматически при старте игры.

## [0.2.0] — 2026-10-01

### Добавлено
- Квестовая механика: подбор плюшевого мишки + взаимодействие с кроватью.
- Система «Ярости» монстра: ускорение и увеличение радиуса обнаружения после подбора мишки.
- Видео кат-сцены пробуждения игрока.
- Видео экрана смерти с наложенными звуковыми эффектами.
- Система подсказок взаимодействия («Нажми E»).
- Менеджер квестов `QuestManager` с отслеживанием прогресса.

### Изменено
- ИИ монстра расширен: добавлены состояния Patrol, Chase, Attack.
- Скрипт кровати `Bed.cs` переписан с поддержкой проверки дистанции и состояния мишки.

### Исправлено
- Исправлена ошибка «слишком далеко от кровати» — увеличена дистанция взаимодействия.
- Устранена гонка условий (Race Condition): монстр теперь мгновенно останавливается при победе игрока.
